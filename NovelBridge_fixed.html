How NovelBridge works

A short guide to add a novel, configure translation, and export an EPUB.

1. Add a novel

Open Library, click Add Novel, and paste a supported novel URL. Scrape Chapters loads the available chapter list.

2. Configure translation

Open API Keys, edit a provider, paste your API key, choose a model, and click Save All. Use Auto or select a provider in the novel details.

3. Translate chapters

Select chapters and start translation. Failed chapters can be retried after checking the provider key, quota, model, and internet connection.

4. Build your book

When chapters are translated, click Build EPUB. The finished file is written to the output folder and can be opened in an ebook reader.

Provider example: Google Gemini

In API Keys, choose Google Gemini and enter your key. Example model: gemini-3.5-flash-lite. Example Base URL: https://generativelanguage.googleapis.com. Keep the Base URL without a trailing /v1 unless your provider documentation specifically requires it.

GEMINI_API_KEY=your-secret-key
GEMINI_MODEL=gemini-3.5-flash-lite
GEMINI_BASE_URL=https://generativelanguage.googleapis.com

Common problems

No API key: configure one in API Keys. Rate limit: wait or switch provider. Unsupported URL: check Add Website. Missing chapters: retry failed chapters before building the EPUB.
